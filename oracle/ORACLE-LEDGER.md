# Oracle behavior ledger

Pinned oracle: Oban OSS `v2.24.1`, Git commit
`64b8481e5383f6bc46b7a5284e4ced3202dec9d5`, Apache-2.0. Harness command:
`nix develop --command ./scripts/test-postgres.sh`. The shell starts a fresh
local PostgreSQL cluster and separate Grind, schema-migration, storage-route,
Oban, and external-consumer databases; it removes the cluster on exit. Oban is
configured with `Oban.Engines.Basic`, `default: 1`, no plugins, and its own
migration. The latest full harness run reported PostgreSQL `16.15`, Elixir `1.18.5`,
OTP `28`, Postgrex `0.22.4`, and `69 passed, 0 failures` for the root Gleam
package tests, followed by Oban success, exhaustion, retry, and snooze
observations and `3 passed, 0 failures` for the external consumer. That run used
port `32453`; its exact output is in `/tmp/grind-v10-full-final.log`. The runner selects a fresh random port
each time. The Oban auto-polling supervisor is stopped before the manual retry
and snooze observations use the same repository and queue.

Normalization used for comparisons: omit generated job IDs and wall-clock
timestamps; compare event outcome and committed state; normalize Oban
`completed` to Grind `succeeded`; preserve queue, attempt count, and user value.
Oban's success value is integer `42`; Grind's typed JSON output is string
`"42"`, an intentional codec-level difference. Oban error metadata is not
equivalent to Grind's caller-owned typed error value. No Oban Pro capability is
inferred from this OSS oracle.

An early standalone pure resolver experiment was removed when the response
resolver was consolidated into the same worker-definition path used by queue
execution. Its separate tests are not counted as production behavior evidence.
The public retry policy receives typed business failures only; worker death,
invalid input, and runtime faults do not enter that callback.

Evidence categories are intentionally distinct: a faithful port reproduces a
named upstream test contract; differential evidence requires both systems to
run against equivalent isolated initial conditions; inspired tests cover a
related behavior without claiming identical contract; original Grind tests
exercise requirements absent from the public Oban oracle. A source read or an
unrun local test is not passing evidence.
